# simple_fuzzer 使用文档

## 一、环境准备

```bash
cd simple_fuzzer

# 推荐使用 uv 管理环境
uv sync
```

项目仅依赖 Python 标准库，无需额外安装。最低 Python 3.8。

## 二、快速开始

```bash
# 最简单的运行：Sample 1，默认 path 调度器，300 秒
uv run main.py --sample 1

# 指定运行时长和调度策略
uv run main.py --sample 3 --run-time 60 --schedule rare_line
```

## 三、参数说明

| 参数 | 类型 | 可选值 | 默认值 | 说明 |
|------|------|--------|--------|------|
| `--sample` | int | 1 / 2 / 3 / 4 | 4 | 选择被测程序 |
| `--run-time` | int | 任意正整数 | 300 | fuzzing 运行时长（秒） |
| `--schedule` | str | path / size / coverage_size / rare_line | path | 调度策略 |
| `--output-dir` | str | 任意目录路径 | `_result` | 结果输出目录 |
| `--quiet` | flag | — | 关闭 | 隐藏实时状态表 |
| `--resume` | flag | — | 关闭 | 从磁盘恢复上次状态继续运行 |

## 四、调度策略选择

| 策略 | 参数值 | 原理 | 适合场景 |
|------|--------|------|----------|
| 路径频率反比 | `path` | 触发罕见路径的种子获得更高能量 | 通用，复杂分支 |
| 输入长度反比 | `size` | 短输入获得更高能量 | 追求执行速度、核心逻辑 |
| 覆盖行数正比 | `coverage_size` | 单次覆盖行数多的种子获得更高能量 | 深层状态探索 |
| 罕见行反比 | `rare_line` | 触发冷门代码行的种子获得更高能量 | 未探索分支突破 |

**建议**：不确定时先用 `path`（默认），需要突破瓶颈时换 `rare_line`。

## 五、运行示例

### 5.1 快速验证

```bash
# 对 Sample 1 快速跑 10 秒，静默模式
uv run main.py --sample 1 --run-time 10 --quiet
```

### 5.2 长时运行

```bash
# Sample 3 用罕见行策略跑 120 秒
uv run main.py --sample 3 --run-time 120 --schedule rare_line
```

运行时实时显示状态表：

### 5.3 对比实验

```bash
# 依次测试所有调度策略
for s in path size coverage_size rare_line; do
    echo "=== $s ==="
    uv run main.py --sample 3 --run-time 30 --quiet --schedule $s
done
```

### 5.4 断点续跑

```bash
# 先跑 60 秒（自动持久化）
uv run main.py --sample 2 --run-time 60 --schedule rare_line

# 中断后恢复再跑 30 秒
uv run main.py --sample 2 --run-time 30 --schedule rare_line --resume
```

恢复成功时显示：

```
[resume] Restored 3 seeds, 13 covered lines, 2 crashes from disk.
```

## 六、输出文件

运行后在 `_result/` 目录生成：

| 文件 | 说明 |
|------|------|
| `Sample-X.pkl` | 最终结果（覆盖行、崩溃集合、起止时间） |
| `Sample-X_population.pkl` | 中途持久化的种子种群 |
| `Sample-X_crashes.pkl` | 去重后的崩溃记录（hash → 最短输入） |
| `Sample-X_evicted.pkl` | 被淘汰的种子归档 |

### 查看结果

```python
from utils.object_utils import load_object

res = load_object("_result/Sample-1.pkl")
print(res)
# Covered Lines: 10, Crashes Num: 6, Start Time: ..., End Time: ...
```

## 七、被测程序一览

| Sample | 函数 | 源码行 | 难度 | 覆盖目标 |
|:---:|------|:---:|:---:|------|
| 1 | `sample1(s)` | 10 | 低 | 浮点运算 + 递归 + 三个分支 |
| 2 | `sample2(s)` | 12 | 中 | 字符串分割/格式化 + 条件数学运算 |
| 3 | `sample3(s)` | 10 | 高 | 多级字符校验 + 断言 + 异常抛出 |
| 4 | `sample4(s)` | 3 | — | HTML 解析器内部代码 |

## 八、注意事项

- `--quiet` 模式下不显示状态表，适合脚本批量运行
- `--resume` 仅在之前运行生成了持久化文件时才有效，否则自动跳过
- 不同 Sample 的持久化文件通过文件名前缀隔离，互不影响
- 不建议同时运行同一 Sample 的多个实例，持久化文件会互相覆盖
